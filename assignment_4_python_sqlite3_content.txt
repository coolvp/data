QUESTION 3: Data Insertion

Task:
Write a Python script using sqlite3 to insert single and multiple products into the products table using execute() and executemany(), then display the affected rows and last inserted ID.

Python Script:

import sqlite3

conn = sqlite3.connect("inventory.db")
cursor = conn.cursor()

# Insert single product
cursor.execute(
    "INSERT INTO products (name, quantity, price) VALUES (?, ?, ?)",
    ("Laptop", 50, 1200.50)
)

print("Single product inserted.")
print("Rows affected:", cursor.rowcount)
print("Last inserted ID:", cursor.lastrowid)

# Insert multiple products
products = [
    ("Mouse", 100, 25.00),
    ("Keyboard", 75, 75.00)
]

cursor.executemany(
    "INSERT INTO products (name, quantity, price) VALUES (?, ?, ?)",
    products
)

print("Multiple products inserted.")
print("Rows affected:", cursor.rowcount)
print("Last inserted ID:", cursor.lastrowid)

conn.commit()
conn.close()

QUESTION 7: Transaction Control (commit & rollback)

Task:
Write a Python script using sqlite3 to demonstrate commit() and rollback() by inserting products and verifying the changes.

Python Script:

import sqlite3

conn = sqlite3.connect("inventory.db")
cursor = conn.cursor()

cursor.execute(
    "INSERT INTO products (name, quantity, price) VALUES (?, ?, ?)",
    ("Tablet", 20, 300.00)
)
print("Tablet inserted.")
conn.commit()
print("Commit completed.")

# Display products after commit
cursor.execute("SELECT * FROM products")
products = cursor.fetchall()
print("\n----- Products After Commit -----")
for product in products:
    print(
        f"ID: {product[0]}, "
        f"Name: {product[1]}, "
        f"Quantity: {product[2]}, "
        f"Price: {product[3]}"
    )

cursor.execute(
    "INSERT INTO products (name, quantity, price) VALUES (?, ?, ?)",
    ("Webcam", 50, 45.00)
)
print("\nWebcam inserted.")
conn.rollback()
print("Rollback completed.")

cursor.execute("SELECT * FROM products")
products = cursor.fetchall()
print("\n----- Products After Rollback -----")
for product in products:
    print(
        f"ID: {product[0]}, "
        f"Name: {product[1]}, "
        f"Quantity: {product[2]}, "
        f"Price: {product[3]}"
    )

conn.close()

QUESTION 8: Database Backup using iterdump()

Task:
Write a Python script using sqlite3 to back up the inventory.db database into an inventory_backup.sql file using iterdump().

Python Script:

import sqlite3

conn = sqlite3.connect("inventory.db")

with open("inventory_backup.sql", "w") as file:
    for line in conn.iterdump():
        file.write(line + "\n")

print("Database backup created successfully.")

conn.close()

QUESTION 9: Export Data to CSV

Task:
Write a Python script using sqlite3 and csv to export all products from the products table to products_export.csv with column headers.

Python Script:

import sqlite3
import csv

conn = sqlite3.connect("inventory.db")
cursor = conn.cursor()

cursor.execute("SELECT * FROM products")
products = cursor.fetchall()

column_names = [description[0] for description in cursor.description]

with open("products_export.csv", "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(column_names)
    writer.writerows(products)

print(f"{len(products)} products exported successfully to products_export.csv")

conn.close()
